## Our Mission

Simplify, streamline, and accelerate business intelligence through **AI**.

### What We Do:
- **Intelligent Process Automation (IPA):** Automating cognitive tasks, data pipeline ingestion, multi-modal workflows, and customer engagement pipelines effortlessly.
- **OpenEuroLLM Sovereign AI Initiative:** Advancing multilingual and multi-modal models tailored for European languages, culture, and high-precision linguistic nuances.
- **Local-First & Edge Deployment:** Providing lightweight, super-fast vision & text models optimized to run locally via Ollama, enterprise servers, or edge devices with zero data leakage.

## Quick Start with Ollama

Running any **OpenEuroLLM** model locally is easy!

<div align="center">
  <img src="./1.png" alt="Job Automation Overview" width="450" />
</div>

### 1. Install Ollama
Download and install Ollama from [ollama.com/download](https://ollama.com/download):


### 2. Run an OpenEuroLLM Model

```bash
# Example: Run OpenEuroLLM German
ollama run jobautomation/OpenEuroLLM-German

# Example: Run OpenEuroLLM Italian
ollama run jobautomation/OpenEuroLLM-Italian

# Example: Run OpenEuroLLM Catalan
ollama run jobautomation/OpenEuroLLM-Catalan
```

### 3. Chat with the Model
OpenEuroLLM models support multi-modal vision inputs. You can pass images along with text questions and vice-versa. For example: asking the model to identify objects in a diagram or a picture.
